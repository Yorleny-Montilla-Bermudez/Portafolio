# Portafolio Personal – Yorleny Montilla Bermúdez

Este es el inicio de mi portafolio como desarrolladora web frontend. Está construido con HTML y CSS puro, y está en desarrollo. Incluye una estructura inicial del sitio con secciones como presentación personal, proyectos, contacto y enlaces a redes.

## 🚧 Estado del proyecto

Este proyecto está en construcción. Iré añadiendo funcionalidades, mejoras de diseño, y optimizaciones de accesibilidad y rendimiento.

## ✨ Características

- Diseño responsive básico
- Imagen de perfil y elementos visuales personalizados
- Secciones para información personal, proyectos y contacto
- PDF adjunto con una versión inicial de mi portafolio

## 🛠 Tecnologías utilizadas

- HTML5
- CSS3

## 📌 Objetivo

Usar este proyecto como base para practicar y demostrar mis habilidades como desarrolladora frontend.
